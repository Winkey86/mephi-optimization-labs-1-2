# Лабораторная работа 1

Песковацков Илья Александрович, Б24-517, N=19, Q=1, Y=26, вариант 17, seed 10119.
Тема: ассортимент пекарни, 8 изделий и 3 печи, максимизация прибыли.

Из корня общего комплекта после установки зависимостей:

```bash
python -m pip install -r requirements.txt
python lab1.py
```

Полный запуск, включая первоначальные самопроверки: `python run_all.py`.
Данные этой работы: `lab1/data/variant.json`. Входные данные и код разделены.
Генератор: `generate_data.py`, алгоритм NumPy PCG64, seed 10119.

Результат записывается в `lab1/results/`. Главные файлы:

- `base_solution.csv`, `deficit_solution.csv` — планы в партиях и изделиях;
- `base_constraints.csv`, `deficit_constraints.csv` — расход и цены часов;
- `scenarios.csv` — базовый, дефицитный и стрессовый сценарии;
- `verification.json` — независимая проверка, конфликт в стрессе и проверки двойственной задачи;
- `shadow_experiments.csv` — прогноз и реальный эффект теневой цены;
- `dual_solution.csv`, `dual.log` — самостоятельное решение полной двойственной модели;
- `elastic.csv`, `elastic.log` — минимальное восстановление мощности;
- `benchmark.csv`, `benchmark_trials.csv`, `benchmark_*_input.json` — 10 размеров, два алгоритма, три повтора;
- `*.log`, `*.lp` — реальные логи и экспорт моделей;
- `plan.png`, `benchmark.png` — графики.

Итоговый отчёт: `report.pdf`, редактируемый исходник `report.docx`, текст `report.md`.
В отчёте выделены три задания со звёздочкой; бенчмарк одновременно выполняет дополнительное задание.
При повторном расчёте существующие файлы результатов перезаписываются; отчёты обновляются отдельно.
Подробности среды, единого запуска и повторного создания отчётов — в корневом README.md.
