## Установка и запуск

Проверено в чистом окружении Python **3.12.14**. Для установки рекомендуется Python 3.12.
Первичная установка требует доступа к PyPI; сами расчёты выполняются локально.

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python run_all.py
```

Windows: вместо `source .venv/bin/activate` выполните `.venv\Scripts\activate`.

Последняя команда решает **обе** лабораторные и выполняет независимые проверки.
Отдельно: `python lab1.py` или `python lab2.py`.
Повторная генерация исходных данных и расчёт: `python run_all.py --generate`.
Регрессионные тесты: `python -m unittest -v`.

Версии библиотек закреплены в [requirements.txt](requirements.txt),
фактическая среда расчёта — [environment.json](environment.json).
Решатель использует один поток и seed 10119, presolve включён;
допуск независимой проверки — **10⁻⁷**. Запуск не требует коммерческого ПО или ключей API.

**Повторный расчёт перезаписывает `lab1/results/` и `lab2/results/`.**
Отчёты не перезаписываются автоматически: измеренное время может отличаться на другой машине.
Чтобы обновить отчёты после изменения данных или нового замера:

```bash
python -m pip install -r requirements_authoring.txt
python build_reports.py
```

Эта команда создаёт DOCX и Markdown. Для пересборки PDF требуется LibreOffice:

```bash
libreoffice --headless --convert-to pdf --outdir lab1 lab1/report.docx
libreoffice --headless --convert-to pdf --outdir lab2 lab2/report.docx
```

На macOS команда может называться `soffice`. Готовые PDF уже включены в репозиторий.

## Проверенные результаты

**ЛР 1.** Базовая прибыль — **44 783 руб.** Снижение ресурса первой печи на 20%
даёт **37 975,56 руб.** Стресс действительно несовместим: обязательный выпуск
требует 6 ч первой печи при лимите 4,8 ч. Все допустимые планы проверены независимо.
Показаны тени активных ограничений, локальный прогноз и фактическое изменение прибыли.

Дополнительное задание — сравнение симплекса и IPM.
Три расширения со звёздочкой: бенчмарк на 10 размерах с тремя повторами,
полная отдельная двойственная модель и эластичный фильтр несовместимости.
Матрицы бенчмарка, результаты и логи каждого запуска приложены.

**ЛР 2.** Базовая стоимость — **120 651 руб./сутки** за перевозку **195 т/сутки**.
Рассчитаны снижение ёмкости, спрос +20%, отказ самой загруженной физической дуги
С4→М5 ЖД и совместный стресс. При отказе стоимость становится **123 511 руб./сутки**.
Проверены все 11 узлов и все 49 дуг, включая 9 технических.
Есть двойственные оценки, тест изменения ёмкости и сравнение с жадной эвристикой.

Дополнительное задание — целочисленная версия с условными неделимыми отправками по 1 т.
Её цель совпадает с LP благодаря сетевой структуре и целым данным.
Это не расписание реального автопарка; допущение явно указано в отчёте.

Теневая цена действует локально до смены базиса.
Совпадение жадного плана ЛР2 с оптимумом на этих данных не является гарантией эвристики.
